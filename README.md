# Karunakaran A — Cybersecurity & Ethical Hacking Portfolio 🛡️✨

[![Live Demo](https://img.shields.io/badge/Live-Demo-00d2ff?style=for-the-badge&logo=vercel&logoColor=white)](https://portfolio-karunakarans-projects.vercel.app/)
[![GitHub Repo](https://img.shields.io/badge/GitHub-Repository-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/karuna0733/portfolio)

A state-of-the-art, 3D interactive portfolio website designed for **Karunakaran A**, Cybersecurity Analyst & Ethical Hacker. Built with modern web standards, custom CSS design tokens, dynamic glassmorphism UI, and an interactive Three.js 3D background grid.

---

## 🌟 Key Features

- 💻 **Interactive 3D Background**: Dynamic particle grid matrix rendering powered by **Three.js**.
- 💎 **Glassmorphism Design Tokens**: Ultra-sleek dark cyber aesthetic using custom HSL colors, neon cyan/purple glows, and frosted glass cards.
- 📱 **Fully Responsive**: Flawless layout across desktops, laptops, tablets, and smartphones.
- 🎯 **Specialized Sections**:
  - **Hero Section**: Profile avatar card, real-time status badges, quick actions, and socials.
  - **About Me**: Specialized profile breakdown and core domain focus.
  - **Skills & Stack**: Interactive skill pills and proficiency breakdown (Cybersecurity, Ethical Hacking, Intrusion Detection, Multi-Agent Systems).
  - **Projects Showcase**: Interactive cards detailing security projects and research.
  - **Certifications & Education**: Academic background and industry certifications.
  - **Contact Section**: Social handles, email, and contact form interface.

---

## 🛠️ Tech Stack

- **Structure**: HTML5 (Semantic tags, SEO optimized)
- **Styling**: Modern Vanilla CSS3 (CSS Variables, Flexbox, Grid, Glassmorphism, CSS Animations)
- **3D & Logic**: JavaScript (ES6+), [Three.js](https://threejs.org/) for webGL canvas rendering
- **Typography**: Google Fonts (*Space Grotesk*, *Plus Jakarta Sans*, *JetBrains Mono*)
- **Deployment**: [Vercel](https://vercel.com)

## 🚀 Local Development

To run this portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/karuna0733/portfolio.git
   cd portfolio
   ```

2. **Open with Live Server or local browser:**
   - Double-click `index.html` or `portfolio.html` to open directly in any standard browser.
   - Alternatively, use VS Code extension **Live Server** or run a simple local web server:
     ```bash
     npx serve .
     ```

---

## 🌐 Deploying to Vercel

This repository is configured with `index.html` at the root, making zero-configuration deployment to Vercel fast and seamless:

1. Import the repository in your [Vercel Dashboard](https://vercel.com/new).
2. Click **Deploy**.
